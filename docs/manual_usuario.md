# Manual de Usuario y Guía de Operación: Sistema AIOps

## 1. Introducción y Descripción de la Interfaz
La aplicación interactiva desarrollada en **Streamlit** permite a los ingenieros de Site Reliability Engineering (SRE) y administradores de infraestructura simular y evaluar el comportamiento del modelo de detección de anomalías en tiempo real. 
La interfaz cuenta con un diseño limpio, barra lateral de configuración, pestañas de navegación intuitivas y visualizaciones gráficas interactivas basadas en Plotly.
